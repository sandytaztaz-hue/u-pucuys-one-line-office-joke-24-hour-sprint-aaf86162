An entry for the [One-Line Office Joke: 24-Hour Sprint](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162) bounty on make.fun.

The program (`main.py`) writes a single-line joke about office life to `/output/entry.txt`:

> I log eight hours a day in my timesheet and spend seven of them deciding what to log.

One line, one sentence, setup first and punchline last. The joke is a fixed
string, so the program is fully deterministic: every run writes exactly the
same bytes. It stays well under the competition's 200-character limit.

## Run

```sh
python3 main.py
```

This writes `/output/entry.txt`.
